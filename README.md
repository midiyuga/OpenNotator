# OpenNotator v0.1.1 no-Tk build

This build avoids Tkinter because some macOS Python installs show the Tk warning but never open a window.

## Use

1. Put `.SON` files in `SON_FILES_HERE`
2. Double-click `OpenNotator.command`
3. It converts the files and opens an HTML report in your browser.

Outputs:
- MIDI files: `Converted_MIDI_Output`
- Report: `Reports/OPEN_ME_OpenNotator_Report.html`
